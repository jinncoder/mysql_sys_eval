# MYSQL_SYS_EVAL

A MySQL plugin for system execution.

Reference (thank you): 

* [https://github.com/mysqludf/lib_mysqludf_sys/blob/master/lib_mysqludf_sys.c](https://github.com/mysqludf/lib_mysqludf_sys/blob/master/lib_mysqludf_sys.c)!!!
* [https://dev.mysql.com/doc/extending-mysql/8.0/en/writing-plugins-overview.html](https://dev.mysql.com/doc/extending-mysql/8.0/en/writing-plugins-overview.html)


Note: *Requires zig@0.16.0*

## Usage

```bash
zig build
```

### Testing

```bash
zig build
docker compose build
docker compose up
```
